기술 목록

1. HTML

웹 표준과 가독성을 준수하는 시멘틱 구조 설계에 능숙합니다. 특히 CSS3 애니메이션 효과 및 키프레임 속성을 깊게 이해하여, 외부 스크립트 도구를 빌리지 않고도 다채로운 인터페이스 전환 효과를 매끄럽게 처리할 수 있는 높은 수준의 코딩 훈련을 수료했습니다.

2. JavaScript (ES6+)

비동기 처리 기법을 이용해 공공 데이터 API를 유연하게 핸들링하고 파싱하는 역량을 갖추었습니다. 웹 페이지 내부의 DOM 객체를 정밀하게 조작할 수 있어 다이내믹한 슬라이드, 모달 레이어 팝업 윈도우, 상호작용형 가상 컴포넌트 기능 등을 순수 자바스크립트로 직접 구현이 가능합니다.

3. Java (Spring Boot)

객체지향 프로그래밍에 대한 높은 이해도를 바탕으로 견고한 백엔드 서버 로직을 설계할 수 있습니다. 관계형 데이터베이스인 MySQL과 연동하여 회원가입, 로그인 권한 인증, 게시판 CRUD 등 서비스 운영에 반드시 필요한 핵심 API 통신 구조를 기획하고 능숙하게 구축해 보았습니다.
