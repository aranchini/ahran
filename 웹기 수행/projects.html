프로젝트 목록

1. 나의 첫 번째 웹페이지 만들기

이 프로젝트는 HTML과 CSS의 기초를 배우고 처음으로 혼자 힘으로 완성해 본 개인 포트폴리오 웹사이트입니다. 시멘틱 태그를 바르게 사용하여 구조를 잡았고, CSS를 활용해 메뉴바에 마우스 오버 효과와 애니메이션을 직접 적용해 보았습니다. 코드를 직접 짜보면서 웹 브라우저에 내가 만든 화면이 그대로 나타나는 과정이 정말 신기했고 웹 개발에 흥미를 느끼게 된 계기였습니다.

2. 자바스크립트 미니 계산기 구현

학교 동아리 활동 시간에 친구들과 팀을 이루어 진행한 자바스크립트 사칙연산 계산기 프로그램입니다. HTML로 기본적인 버튼과 숫자 UI 화면을 배치하고, CSS로 깔끔한 디자인을 입힌 뒤 자바스크립트의 이벤트 리스너 함수를 구현하여 실제 덧셈, 뺄셈, 곱셈, 나눗셈이 작동하도록 만들었습니다. 팀원들과 의견을 나누며 협업하는 즐거움을 배웠습니다.
