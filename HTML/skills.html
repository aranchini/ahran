기술 목록

HTML

저는 웹 기초 수업을 통해 HTML을 처음 접했는데요. HTML은 웹 페이지의 뼈대를 담당하는 언어로 화면에 들어갈 텍스트,이미지, 버튼 같은 구성 요소(콘텐츠)를 배치하는 역할을 합니다.

CSS

HTML로 세운 뼈대를 예쁘게 꾸며주는 디자인 언어로 글자 색상, 배경, 폰트, 그리고 요소들의 위치를 깔끔하게 정렬하고 배치하는 역할을 합니다.

Python (파이썬)

파이썬은 학교 와서 가장 먼저 접해본 프로그래밍 언어로 기본적인 문법인 변수, 조건문, 반복문, 함수 등을 자유롭게 다룰 수 있습니다.텍스트 기반의 간단한 가위바위보 게임이나 성적 계산 프로그램을 직접 구현해 보면서 프로그래밍의 논리적인 사고력을 많이 기를 수 있었습니다.
