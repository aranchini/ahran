기술 목록

HTML5 / CSS3

저는 웹 프로그래밍 수업을 통해 HTML5와 CSS3의 핵심적인 사용 방법을 완벽하게 익혔습니다. 웹 표준에 맞는 구조적인 시멘틱 태그를 활용하여 웹사이트의 뼈대를 튼튼하게 구축할 수 있으며, 다양한 스타일 속성과 flex 레이아웃을 사용해 화면을 깔끔하게 정렬할 수 있습니다. 또한, 자바스크립트를 쓰지 않고도 CSS만으로 역동적인 애니메이션 효과나 마우스 반응 효과를 줄 수 있는 능력을 키웠습니다.

Python (파이썬)

파이썬은 가장 먼저 접해본 프로그래밍 언어로, 기본적인 문법인 변수, 조건문, 반복문, 함수 등을 자유롭게 다룰 수 있습니다. 터틀 그래픽 라이브러리를 사용해 간단한 그림을 그리거나 화면에 움직이는 게임을 만들어 본 경험이 있으며, 텍스트 기반의 간단한 가위바위보 게임이나 성적 계산 프로그램을 직접 구현해 보면서 프로그래밍의 논리적인 사고력을 많이 기를 수 있었습니다.

C 언어

C 언어는 컴퓨터의 구조와 메모리 개념을 이해하기 위해 공부하기 시작했습니다. printf와 scanf를 이용한 기본적인 입출력부터 시작해서 배열과 포인터, 구조체의 기초적인 개념까지 열심히 학습하고 있습니다. 조금 까다롭고 어렵긴 하지만 알고리즘 문제를 풀 때 C 언어를 사용해 보면서 코드가 컴퓨터 내부에서 어떻게 더 효율적으로 작동하는지 원리를 배울 수 있어서 재미있습니다.
